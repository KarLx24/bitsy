# Bitsy BT-8

An interactive 3D robot companion that starts as an armoured cube and transforms into six forms: Spider, Shark, Scorpion, Manta, Wasp and Piranha.

**Live page:** open `index.html`, or the GitHub Pages link for this repo.

What you can do on the page:
- pick a form and watch Bitsy take itself apart and rebuild as the new one
- click the sections on the left to see each part open up
- change the colour line (the new colour sweeps across the robot)
- drag to rotate, scroll or pinch to zoom, double-click to reset
